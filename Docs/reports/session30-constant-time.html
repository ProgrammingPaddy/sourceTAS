01Point-to-point in batch — the shape transfers consume

Route solving asks the same question thousands of times: one boarding state, many candidate exits. Batch mode organizes the answer once per start — every enumerated reversal-schedule endpoint goes into a spatial hash (834 endpoints at 30 ticks, 21,374 at 90) — and each target then seeds from its own cell neighborhood, kernel-verifies six candidates, climbs the best, and finishes with the exact-hit endgame. A target the neighborhood misses falls back to the full solver, so batch answers are never worse than single-shot.

02Board→exit answers in fractions of a microsecond

The ride reach sweep now builds a per-layer cell index (in-plane cell → node) during its organization pass. A target query reads its 3×3 cell neighborhood instead of scanning the layer: 0.2–0.3 µs per answer across all three test ramps, roughly 10,000× the layer scan. The indexed answers land at lattice resolution (mean ~30 units, worst 55, all inside the 96-unit contract); the nearest-node full scan (0.7-unit mean) remains available where precision beats speed. Both return exact, replayable input schedules.

03Two new certified culls — one earned the hard way

B13, minimum departure resource for a gap ("cover distance D within N ticks and arrive at speed V"): the closed-form speed ceiling gives one bound, the certified travel integral the other, both provably monotone in departure speed — constant-time. Its falsifier is the strongest attack available: the A11 solver itself, launched from 0.98× the bound at the cheapest target. Twenty-four attacks, zero refutations.

B14's first two drafts were wrong, and the falsifier caught both. The minimum incoming speed at a face for a required post-board speed was first computed by bisection assuming the best retained speed grows with incoming horizontal speed — refuted at 20/127 configurations: post-board speed is not monotone in horizontal speed (a slow-horizontal, fast-vertical arrival can retain more). The exact piecewise-quadratic reformulation then missed one root — the zero-loss band's own feasibility crossing — and was beaten at 22/185. The final version enumerates every branch boundary and quadratic root of the window's minimum-loss law and takes the true infimum in closed form, constant-time: 185 configurations × 401 exact-clip headings at 0.98× the bound, zero violations.
