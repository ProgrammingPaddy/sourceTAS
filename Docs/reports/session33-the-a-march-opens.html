03The bug the march found on day one

The brake-probe stride N/8 is zero when N < 8 — and the loop guard continued forever. Both fixed-N solvers (SolveFixedN and the batch fallback in SolveTargetBatch) carried this infinite loop since session 28; no caller ever passed a small N until A12's scan started at N = 1 and hung the suite. Both sites now clamp the stride. This is the quiet argument for the whole directive: closing rows means walking domains nothing else walks.

After the fix, every consumer of the touched solvers reran green: capp2p 21/0, capxfer 8/0, capmat 9/0.

04capmin — minimum ride time and the edge launch

Two rows on the ride side, gated the same way: agreement, witnesses, and assumption-free laws.

A21, CapRideReach::MinRideTime — the first A20 layer that answers an in-plane target within the lattice contract. The implementation queries the cell index first but confirms every miss with the exhaustive scan, so the answer equals the brute per-layer scan by construction: 50/50 agreement measured anyway, and 12/12 minimum-time witnesses replayed as engine continuations keeping contact every tick — zero boundary fringe, because minimum-time paths run the interior. The honest efficiency note is that the confirm-every-miss rule costs the index its speed edge here (857 µs vs 696 µs brute); correctness kept the tiebreak, and both sit under the row's 1 ms target.

A26, CapLaunch::Detector — the unified leave-ground event detector, fed by exact rollouts, capturing both boundary states. Its gates assume nothing about the engine's ground-check internals:

· One geometric constant. Across three approach speeds, the launch threshold brackets to (270.706, 272.437] — a single fixed number, whatever the ground-check's quadrant geometry makes it. The bracket contains 256 + 16 = edge + hull half-width: the A3 hull-overhang prediction, confirmed by measurement.

· The capture is complete. Re-anchoring the captured post-launch state reproduces the original rollout bitwise for 30 ticks, all three trials.

· The handoff is exact. The first clean airborne tick after launch matches the A1 vertical recurrence bitwise in both z and vz — the launch state plugs straight into every air capability.
