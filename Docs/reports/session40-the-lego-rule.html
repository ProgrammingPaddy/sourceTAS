01The rule

User directive, verbatim: "You can have multiple approaches to each algorithm... Nothing should ever regress while working on another, that's the entire point of having atomic units that can be combined like lego."

Now binding semantics #8: never edit approach A into approach B — keep both intact and compose them as ordered fallback portfolios. Each later strategy runs only while the previous ones left the input unsolved, and evaluations update the answer only on improvement, so the composition is monotone by construction and its coverage is the union of the constituents'. "Improved X but regressed Y" is never a tradeoff to accept — it signals a missing composition. And enforcement is mechanical: measured per-class coverage pins as hard floor gates under deterministic seeds; floors only ever rise.
